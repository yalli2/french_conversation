# Français Conversation 🇫🇷

국제학교 프랑스어 회화 수업용 인터랙티브 학습 사이트입니다.

- **18개 단원 + 발음 가이드** — 대화문(듣기·역할극·따라 말하기), 핵심 문법, 어휘 카드
- **149개 연습문제** — 빈칸 채우기, 객관식, 참/거짓, 연결하기, 문장 만들기, 쓰기, 듣기 문제를 바로 채점하고 점수 저장
- **원어민 음성** — 브라우저 음성 합성(fr-FR). Microsoft Edge의 Natural 음성(Denise, Henri 등), Chrome의 Google français, Apple의 Amélie/Thomas 음성을 권장합니다.

모든 대화문·읽기 자료·연습문제는 수업용으로 새로 각색·작성되었습니다.
